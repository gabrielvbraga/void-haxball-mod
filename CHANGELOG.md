# Changelog

What changed in each version of VOID HaxBall Mod. The text under each version is also the description of its release on GitHub.

## 1.2.0

New: in-app updates and field styles.

- Updates from inside the app: Status > Download and install. The file is checked (SHA-256) before anything is replaced
- Menu size slider (80% to 150%) in Customize > Interface
- Field styles: futsal (wood), sand and ice, besides flat
- Windows notifications when someone mentions your nickname or moves you to a team, plus a VOID sound for team moves (off by default, in Settings)
- Electron updated from 33 to 45, with the latest security fixes
- Fixed: the menu always showed v1.0
- Removed: custom sound files in the Audio tab

## 1.1.0

New: Chat Bubble hotkey.

- Pick a key in Chat & HUD > Chat Bubble shortcut
- Each press turns the bubble on or off
- It does not fire while you type in chat

## 1.0.0

First public release of VOID HaxBall Mod.

- Sidebar menu, color themes, Portuguese/English
- Ad blocking, FPS counter, recording mode (F4) and Chat Bubble
- Recent and favorite rooms, profiles and quick actions
